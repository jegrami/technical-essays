## Topics to Cover

### 1. Introduction
- Purpose of this document

### 2. Basic Anatomy of Your Computer
- What is inside a computer: CPU, memory (RAM), storage, GPU, motherboard. Kept from the original and modernized to include phones and tablets as "computers" too.

### 3. What Happens When You Turn On a Computer?
- The boot process: firmware (UEFI/BIOS), bootloader, loading the operating system. Kept from the original, with updated terminology (BIOS to UEFI, and so on).

### 4. How does your computer identify you when you login?
- User accounts, passwords, and how the OS checks who you are. Kept from the original and expanded to include biometrics, PINs, and cloud-linked accounts.

### 5. What Happens When You Open an App?
- How a program goes from an icon tap or click to running code. Kept from the original and renamed from "run programs," since modern audiences say "apps."

### 6. How Do Input Devices Work?
- Keyboards, mice, touchscreens, and sensors, and how the computer notices input (interrupts, explained simply). Kept from the original and broadened beyond keyboard and mouse.

### 7. How Does Your Computer Do Several Things at Once?
- Multitasking, multiple CPU cores, and background apps. Kept from the original and updated for the multicore reality of modern devices.

### 8. How Does Your Computer Keep Programs from Interfering with Each Other?
- Virtual memory: the simple version
- Virtual memory: the detailed version
- Memory protection today (a simplified, renamed version of the Memory Management Unit topic)
Kept from the original with modernized examples.

### 9. How Does Your Computer Store Things in Memory?
- Numbers: how computers represent them
- Text and characters: how computers store letters and emoji (Unicode)
Kept from the original; the characters topic is expanded to cover Unicode and emoji, which are relevant today.

- How your computer finds a file when you open it
- File ownership, permissions, and security
- What can go wrong: corruption and why backups matter. Expanded to include cloud backup and sync.

### 11. How Do Computer Languages Work?
- Compiled languages

Kept from the original with modernized terminology.

- Names and addresses: domain names and IP addresses
